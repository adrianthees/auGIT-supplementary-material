# Exclusion codes (full-text screening)

Used in [`screening-log.csv`](screening-log.csv). The **first** code that applied was recorded per paper.

| Code | Meaning |
|------|---------|
| **E1** | Does not elicit practitioner selection or trust **signals** for choosing open source dependencies (for example proposes a model/measure or runs an experiment instead of capturing selection criteria) |
| **E2** | Elicits practitioner evidence, but the focus is not dependency selection or dependency trust evaluation (for example contributor security setups) |
| **E3** | Industry summit summary without a dependency selection signal set |

Included papers have an empty exclusion code.
