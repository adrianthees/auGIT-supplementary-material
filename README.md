# auGIT supplementary material

This repository holds reproducibility artifacts for the master thesis **auGIT: A Tool for Audit Trails of Open Source Dependencies** (Adrian Thees, 2026).
It contains material that is too detailed for the thesis body but needed to trace or replicate empirical steps. Starting with the exploratory practitioner literature review for RQ1.
The implementation of the work is available on chains-project/auGIT.
